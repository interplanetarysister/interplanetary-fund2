# Interplanetary Fund — PayPal Hackathon Media (October 2026)

This media pack is derived from real browser renders of the public iFund application at https://interplanetaryfund.base44.app/ . Source screens were captured in headless Chromium at desktop 1440x900 and mobile Pixel 7 emulation. The layouts shown in composites are graphic presentations of captured pixels, not separately verified deployed interfaces.

Do not present this pack as evidence of working payment processing or a formal PayPal partnership. Public campaign examples are captured as displayed by the application, and the screenshot does not imply successful fundraising transactions. No production code or deployment files were changed by this media branch.
